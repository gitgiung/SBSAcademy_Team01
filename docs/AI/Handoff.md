- 완료: 빈 공간으로 뻗은 가시는 지웠다. 주먹 면을 덮던 붉은색은 옆의 근육·외곽선 색으로 바꿨다. 캔버스는 144×144. `.meta`와 스프라이트 rect는 그대로다.

- 검증: 64장 모두 새로 생긴 몸 구멍은 0이다. 남쪽 0번은 가시 75픽셀을 지우고 주먹 면 359픽셀을 살색으로 바꿨다. 남쪽 0·4, 남동 0, 남서 4·7, 동쪽 0·4, 북동 0, 북쪽 0, 서쪽 0을 열어 주먹이 회색 근육이고 어깨·가슴·무릎의 붉은 문양이 남았는지 보았다. Unity 임포트와 플레이는 실행하지 않음.
