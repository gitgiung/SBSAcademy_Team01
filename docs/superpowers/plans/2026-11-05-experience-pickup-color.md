# 경험치 보석 색상 구간

사용자 요청: 경험치량별 색을 임시로 정하고 이후 수정 가능하게 한다. 수치·색 결정은 위임받았다.

구조: 기존 ExperiencePickup에 직렬화 가능한 구간 배열과 대상 SpriteRenderer를 추가한다. 별도 매니저·설정 로더·셰이더·이미지는 만들지 않는다. 공통 DNA(EXP) 프리팹 Inspector에서 조정한다. 색은 보석이 담은 원래 경험치량을 기준으로 결정하며 후속 성장 보정과 분리한다.

임시 기본값: 최소XP 0 파랑(#4DA6FF), 3 초록(#52D681), 4 노랑(#FFD45C), 6 보라(#B58CFF), 7 주황(#FF9E4A), 9 분홍(#FF5E7E). 최대 조건을 별도로 두지 않고 현재 XP 이하인 최소값 중 가장 큰 값을 선택한다. 배열 순서는 무관하며 같은 최소값이면 앞 항목 우선이다. 유효 구간이 없으면 흰색으로 원본 색을 보존한다. 구간 최소값은 유한한0이상만 사용한다.

기존 스프라이트에 tint를 적용하므로 실제 화면 색에는 원본 DNA의 명암/색이 섞인다. 기존 공유 머티리얼을 수정하거나 개별 material 인스턴스를 만들지 않는다. 렌더러는 Inspector 우선, 없으면 자신의 SpriteRenderer→자식 순으로 찾는다.

- [x] Unity 실제 ExperiencePickup으로 기본 구간·경계·설정 변경·순서·빈 설정·렌더러 누락·재초기화 테스트를 먼저 작성하고 기능 부재 실패를 확인한다.
- [x] ExperiencePickup.RawExperience, SetExperienceAmount(float), RefreshExperienceColor()를 추가한다. 기존 Initialize(Transform)도 색을 갱신하고, OnEnable에서 현재 값에 맞춰 외형을 복원한다. 기존 경험치량/끌림/회수 로직은 보존한다.
- [x] 성장 수치/카드 회귀와 전체 관련 소스 컴파일을 실행하고 실제 결과를 기록한다.
- [x] Handoff와 Inspector 수정/확인 절차를 갱신한다. 원본 씬·프리팹·meta·표·패키지를 재저장하지 않는다. 생성시 rawXP·풀링은 다음 단계다.
