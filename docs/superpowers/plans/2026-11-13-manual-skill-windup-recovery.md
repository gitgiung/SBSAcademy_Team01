# 약·강공격 선딜/후딜

사용자 확정: 기존 차징은 유지. 수동 약공격 및 강공격 해제 시 공격 모션 시작, 모션 시간0.25초에 실제 발사, 모션 종료 시 이동 허용. 기존 모션은0.75초이며 Animator 속도를 바꾸면 모션 시간 기준으로 발사/종료가 따라간다. 연사 잔여 발사는 이동 잠금 종료와 분리한다.

기존 PlayerLightSkill의 실행 ID/애니메이션 진행/종료 연결을 표 기반 수동 발사에도 사용한다. 새 매니저나 별도의 타이머 프레임워크를 만들지 않는다. MP/피해/차징/자동 발동은 유지하고 고정 후딜 대기만 제거한다. 수동 태양 탄막은0.25초 발사를 지키도록 문양 그리기 대기를 추가로 적용하지 않으며 자동 발동의 기존 그리기 대기는 유지한다. 모션 중단·Animator 무효화·사망·비활성화 시 실행을 정리한다.

- [x] 기존 실제 Animator 검증에 실제 PlayerLightSkill/PlayerActionGate와 시간 경계·중복/이전 ID·중단/비활성화·일시정지 회귀를 추가해 실패 확인.
- [x] PlayerLightSkill에 표 기반 발사 콜백을 등록하고0.25초에 한 번 실행. 상태 종료로 잠금 해제.
- [x] 약/강 수동 경로를 연결하고 CastShots의 고정 후딜/잠금 해제 제거. 자동 발동 유지.
- [x] 현재 소스 컴파일, 실제 Animator 회귀, 인수인계 및 직접 확인 절차 기록.
