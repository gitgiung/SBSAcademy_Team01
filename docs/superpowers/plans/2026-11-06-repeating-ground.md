# 반복 바닥과 이동 중 보스전 구현 계획

> Use superpowers:executing-plans to execute and verify each step.

**목표**는 MainTestScene에서 같은 바닥 위를 계속 달리며 보스와 교전할 수 있게 하는 것이다.

**설계**는 기존 Ground Tilemap을 화면 주변으로 확장하는 씬 컴포넌트와 BossEncounterController의 선택적 상대 배치로 나눈다. 맵은 플레이어와 전투 오브젝트의 월드 위치에 관여하지 않는다. 첫 버전의 보스는 기존 추적 및 돌진으로 접근한다.

## 작업 순서

- [x] 검증 사본에서 카메라가 양·음 좌표로 이동했을 때 화면이 덮이는지, 멀어진 확장 타일이 지워지는지 확인한다.
- [x] 기존 Tilemap에 카메라 주변 영역만 쓰고 지우는 RepeatingGround를 연결한다. 기존 Ground의 중앙 타일과 렌더러를 활용한다.
- [x] 멀리 이동했을 때 기존 보스가 시작 위치 대비 배치 간격만큼 떨어진 위치에서 활성화되는지 확인한다.
- [x] MainTestScene에서만 상대 배치를 켠다. 다른 씬의 설정은 기존 위치를 사용한다.
- [x] 씬 배선, 재로드 후 타일 상태, 보스전 중 타이머와 전투 진행을 검증하고 인수인계에 실행 결과와 수동 확인 절차를 남긴다.
