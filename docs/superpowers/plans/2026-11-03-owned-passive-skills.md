# 보유 스킬 패시브 발사 구현 계획

**Goal:** 보유 공격 스킬마다 독립 주기로 자동 직선탄을 발사한다.
**Architecture:** 기존 PlayerCombat이 보유 슬롯의 실행 시간을 소유하고 Data.SkillData는 패시브 설정만 소유한다. Player가 명시적 프리팹 바인딩을 전달하고, 그 외 리소스는 기존 ResourceManager의 준비된 캐시에서 찾는다. 새 전역 매니저는 만들지 않는다.
**Spec:** 기존 player-skills-design.md의 보유 스킬 패시브 규칙 및 이번 사용자 승인: 불꽃 탄환 피해6/간격3초/탄속3/사거리6. 약공격 MP10/피해10 유지.

## 구현 판단

기존 단일 기본탄을 계속 발사하며 보유탄을 추가하면 중복 공격이 된다. 기본 자동 발사 경로를 보유 스킬 순회로 교체한다. 원래 Player.bulletPrefab 직렬화 참조는 보존하지만 자동 발사에는 사용하지 않는다. 스킬이 없거나 패시브 설정/리소스가 잘못되면 발사하지 않는다.

각 스킬의 첫 유효 표적에는 즉시 발사하고 이후 승인한 간격을 적용한다. 표적 부재 중 만료된 타이머는 발사 가능 상태로 유지하고 지연 프레임의 누적 연사는 하지 않는다. 일시정지/방어 중 타이머를 진행하지 않으며, 비활성화 시 실행 상태를 초기화한다. 기존 약공격 입력 잠금 중 패시브 허용은 유지한다.

## 검증 경계

사용자 요청으로 생략한 병합 전체 선행 검증을 다시 요구하지 않는다. 원본 에디터를 중복 실행하지 않고 기존 짧은 검증 복사본을 사용한다. 실제 MainTestScene/Android 기기 확인은 별도로 명시한다. 씬 전체 재저장, 원본 Bullet 프리팹 수정, 미정 다른 스킬 수치 생성은 하지 않는다.
