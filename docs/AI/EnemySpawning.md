# 몬스터 단계 혼합 설정과 확인

## 기본 동작

`Enemy Spawn System` 프리팹의 `Enemy Spawn Director`는 단계 혼합 모드로 연결돼 있다. `Temp_enemy`의 느린/일반/빠른 좀비와 들개, 각각 6단계로 총 24개를 사용한다. 수치는 프리팹에 작성된 것을 그대로 사용한다.

- `_3min`: 0–3분, `_6min`: 3–6분, …, `_18min`: 15–18분.
- 각 3분 경계부터 이전 단계와 현재 단계를 혼합한다. 다음 단계를 미리 내보내지 않는다.
- 전환 초기값은 90초이며, 비율은 기존 30초 웨이브 경계에서 갱신한다. 예: 3:00 새 단계 0% → 3:30 약 33% → 4:00 약 67% → 4:30 100%.
- 필드에 이미 나온 몬스터는 교체하지 않는다. 새로 생성되는 몬스터의 구성만 바뀐다.
- 네 종류의 Early Weight/Late Weight 초기값은 모두 1이다. 이는 플레이테스트 초기값이며 확정 밸런스가 아니다.
- 기존 스폰 예산·동시 활성 130마리 제한·18분 종료·XP·보스전 진행 정지 규칙은 유지한다.

## 편집 순서

1. Play를 종료하고 임포트·컴파일 완료를 기다린다.
2. `MainScene` → Hierarchy의 `Enemy Spawn System` → Inspector의 `Enemy Spawn Director`를 선택한다.
3. `몬스터 구성 모드`가 `StageMixing`인지 확인한다. 기존 수동 배열은 `ManualWaves`로 바꾸면 다시 사용할 수 있다.
4. `단계 혼합 설정`을 펼친다. `Transition Seconds`는 전환 시간(0–180초), `Types`는 종류별 설정이다. `Stage Prefabs`의 0~5는 0–3분부터 15–18분까지 순서다.
5. 종류별 `Early Weight`/`Late Weight`를 조절한다. 상대 비율이므로 네 종류가 모두 1이면 각각 25%다. 초반/후반 사이의 비율은 진행 시간에 따라 자동 보간한다. 각 끝점에서 모든 종류를 0으로 만들면 설정 오류다.
6. 프리팹을 다시 연결해야 하면 `자동 등록 폴더`를 선택하고 **폴더에서 24개 자동 등록 · 단계 혼합 사용**을 누른다. 기존 전환 시간과 같은 종류의 가중치는 보존한다. 누락/중복/필수 컴포넌트 오류면 기존 연결은 유지한다. Ctrl+Z로 등록을 취소할 수 있다.
7. 씬 인스턴스에서 값을 바꿨다면 씬을 저장한다. 공통 기본값을 바꾸려면 프리팹을 직접 편집하거나 의도한 Override만 Apply한다.

## 정상 결과 확인

실행 전 Inspector 아래 **스폰 비율 미리보기 · 웨이브** 슬라이더를 확인한다. 초기값 기준:

| 웨이브 | 진행 시간 | 새로 스폰되는 구성 |
|---|---|---|
| 1 | 0:00 | `_3min` 네 종류만, 각각 25% |
| 7 | 3:00 | `_3min`만. 전환 시작점의 새 단계 비율은 0% |
| 8 | 3:30 | `_3min` 합계 약 67%, `_6min` 합계 약 33% |
| 9 | 4:00 | `_3min` 합계 약 33%, `_6min` 합계 약 67% |
| 10 | 4:30 | `_6min` 네 종류만, 각각 25% |
| 34 | 16:30 | `_18min` 네 종류만, 각각 25% |

이후 `Tools > Play From Title` 해제 → `MainScene` Play. 실행 중 Inspector의 비율은 현재 진행 웨이브를 표시한다. Hierarchy에서 새로 생성되는 적 이름으로 단계가 맞는지 확인한다. 이전에 나온 적이 남아 있는 것은 정상이다. 보스전에서는 기존 진행 시계가 멈추므로 혼합도 멈추고, 전투가 재개되면 이어진다.

빠른 진행용 기존 컴포넌트 ⋮ 메뉴 `테스트/진행시간 30초 앞으로`는 시계를 건너뛰며 프레임별 스폰 예산 제한도 받는다. 실제 스폰 수나 밸런스를 검증하는 용도로 쓰지 않는다.

## 오류 시 확인

- Console의 첫 오류와 Director의 활성 여부.
- `몬스터 구성 모드`, 단계 프리팹 누락, 종류별 가중치 끝점 합계, 전환 시간 범위.
- MainScene 인스턴스의 `rosterMode`/`stageMixing` Override. 기존 `waves` Override는 혼합 모드에서 사용하지 않는다.
- 자동 등록 시 이름이 `Enemy_movespeed2/3/4_3/6/9/12/15/18min` 또는 `ZombieHound_…min`인지, 같은 이름이 하위 폴더에 중복되지 않는지, 루트에 EnemyHealth/EnemyFollow가 있는지.
- 적이 나오지 않으면 기존 풀·플레이어·카메라·스포너 참조와 동시 활성 제한도 확인한다.

실제 MainScene Play의 난이도·화면 결과와 Android 빌드/기기는 별도로 확인해야 한다.
