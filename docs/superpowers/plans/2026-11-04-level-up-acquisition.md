# 레벨업 선택 획득과 후보 제외

**Goal:** 약공격 카드 선택 시 PlayerLoadout에 보유 등록하고 이후 추첨에서 제외한다. 후보 소진 시 제목 `카드 없음`, 내용 `카드가 소진되었습니다.`와 확인을 표시한다.

**Architecture:** 보유 모델이 중복/빈 슬롯 검증을 유지하고, LevelUpSkillReward가 표 메타데이터를 기존 SkillData로 연결한다. 추첨기는 제외 ID 집합을 받는다. CombatPopupController는 선택 성공 뒤 기존 CompleteLevelUp을 호출한다. 패널은 카드 모드와 안내 모드를 전환한다.

**사용자 결정:** 기본 6칸이 가득 차면 가득 참 안내 후 확인으로 종료한다. 자동 장착·스킬 교체·수치 보상은 추가하지 않는다. 이번에는 약공격만이며 이후 강공격에서도 기존 분류를 보존한다. 실제 레벨업 발생 이벤트는 별도다.

- [x] 획득/중복/가득 참/미장착 유지/추첨 제외·소진 회귀 검증 실패 확인.
- [x] 빈 슬롯 조회·획득 연결·추첨 제외 구현.
- [x] 카드 선택 콜백·일시정지 등록·후보 소진/가득 참 안내와 확인 연결.
- [x] 독립 검증17/17 및 기존4/4 통과, 런타임/에디터 컴파일 종료0. 독립 리뷰 중요 지적 없음, Handoff 갱신. 실제 UI는 미검증.
