# 몬스터 몸체 충돌

- 승인한 범위: 기존 테스트 씬의 적에 Dynamic Rigidbody2D와 일반 몸체 콜라이더를 적용하고, 공격용 Trigger는 유지한다. 적은 물리적으로 서로 막거나 밀 수 있다.
- 재현 테스트: 같은 목표에 몰리는 두 적, 같은 위치에 생성된 적의 겹침 해소, 앞의 적 사망 후 뒤의 적 추적 재개.
- 몸체는 사각 스프라이트 크기에 맞는 BoxCollider2D를 사용한다. 기존 CircleCollider2D는 공격 검출용으로 유지한다.
- 물리 충돌 해결에는 엔진의 작은 접촉 허용 오차가 있으므로 콜라이더 간 침투 깊이 0.02 유닛을 테스트 상한으로 둔다. 동일 지점 생성 시 물리 프레임을 거쳐 겹침을 해소한다.
- 기존 사용자 씬·프로젝트 설정·플레이어 입력은 변경하지 않는다.
- RED: Logs/collision-red.xml — 세 테스트 모두 몸체 콜라이더 부재로 실패.
- 구현: EnemyFollow에 Dynamic/Continuous 몸체, BoxCollider2D 요구, 이동 의사결정 전 및 비활성화 시 잔여 속도 정리. 프리팹 및 기존 생성·업그레이드 도구도 같은 설정을 적용.
- 기존 생성 지점 순환 테스트는 위치 검사 중 물리를 끄도록 분리해 새 충돌 처리의 프레임 타이밍에 의존하지 않게 했다.
- 최종 검증: Unity 6000.5.0f1 PlayMode 전체 26개 통과, 실패·건너뜀 0, 종료 코드 0. Logs/collision-final.xml. 검증 복사본의 소스·프리팹이 실제 작업 폴더와 동일한 해시임을 확인.
- 독립 리뷰: 원본 프리팹에 Dynamic/Continuous, 일반 BoxCollider2D 및 기존 Circle Trigger가 반영됐음을 확인. 추가 수정 사항 없음.
- 그래픽 없는 배치 검증이며 수동 외형 확인은 미실행. 기존 사용자 씬·설정 변경 유지, 커밋·푸시 미실행.
