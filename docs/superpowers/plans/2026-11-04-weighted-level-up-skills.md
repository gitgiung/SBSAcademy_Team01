# 약공격 레벨업 카드 가중 추첨

**Goal:** SkillDatatable.xlsx의 Skill_Rarity 가중치를 읽어 팝업마다 약공격을 최대 3개 중복 없이 표시한다. 사용자 확인: 이번에는 약공격만, 향후 강공격에도 재사용한다.

**Architecture:** 기존 CombatSkillTableExporter가 등급 ID/이름/실수 가중치/프레임 키/색을 JSON에 포함한다. LevelUpSkillDraft는 등급 가중 추첨 후 그 등급의 남은 스킬을 균등 추첨한다. CombatPopupController가 새 팝업 열기에만 추첨하고 기존 LevelUpSelectionPanel에 바인딩한다.

**결정:** 가중치 0/없는 등급은 제외한다. 시너지 가중치 0을 그대로 따른다. 일부 스킬의 Mystic은 등급표 Mythic의 구표기로 연결한다. 부족한 후보는 있는 만큼 표시하고 없는 등급 확률을 남은 양수 가중치로 정규화한다. 보유 중복 획득/보상/레벨업 발생 규칙은 기존 미구현 범위를 유지하며 이번에는 추첨 표시만 한다. 실제 선택 데이터를 전달하는 기존 오버로드는 보존한다.

- [x] 신규 파서/추첨 검증 4개 실패 확인: 등급 내보내기 부재, 추첨기 부재. 기존 7개 통과.
- [x] 등급표 JSON 변환·로딩, 소수 가중치 보존.
- [x] 범위 인자 기반 추첨, 등급 우선·균등 스킬·중복 제거·0 가중치 제외 구현.
- [x] 표의 설명 토큰과 색을 카드에 연결하고 예시 카드 제거, 중복 열기 재추첨 방지.
- [x] 전투 표/추첨 검증 13/13, 장착4/4, 런타임/에디터 컴파일 종료0, 독립 리뷰 중요 지적 없음, Handoff 갱신. 실제 Unity UI는 미검증.
