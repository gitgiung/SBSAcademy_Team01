# GiungTestScene 몬스터 풀 스폰 설계

상태: 사용자 승인 후 구현·검증 완료. 2026-10-28. 전체 PlayMode 55/55 통과.

## 확정 요구

- 대상 씬은 `Assets/9.Scenes/GiungTestScene.unity`다.
- 몬스터 종류와 생성 수는 1분 단위 설정으로 달라진다.
- 각 스포너가 n초 간격으로 l마리씩, 누적 m마리를 생성한다. **m은 스포너 하나당 총량**이다.
- 스포너 생성 위치는 플레이어 카메라 밖이다.
- m마리를 전부 생성한 스포너는 비활성화한다.
- 스포너 개수는 개발자가 설정한다. 몬스터는 플레이어를 추적한다.
- 기존 풀을 사용하고 일반 몬스터 동시 130마리 제한을 스폰 단계에서 적용한다.

## 접근 방식

기존 EnemySpawner를 배치 생성기로 확장하고 씬 컴포넌트 하나가 분별 설정과 스포너 배치를 맡는 방식을 권장한다. 새 전역 매니저나 싱글톤은 만들지 않는다.

각 스포너에 분별 설정을 중복 저장하면 공통 설정 변경과 분 전환을 여러 곳에서 동기화해야 한다. 기존 PoolManager에 게임 시간·종류·추적 규칙을 넣으면 공통 풀의 책임을 벗어난다. 두 방식은 사용하지 않는 제안이다.

## 승인한 구현 동작

- Inspector에서 분별 몬스터 프리팹 목록, n, m, l 및 스포너 개수를 설정한다. 종류가 여러 개이면 목록 순서대로 순환 생성해 임의의 확률 수치를 추가하지 않는다.
- 0~59초에 첫 설정을 적용하고 이후 60초마다 다음 설정을 적용한다. 마지막 설정 이후에는 마지막 설정을 유지한다.
- 매분 각 스포너에 최대 한 번의 생성 작업을 할당한다. 비활성 스포너는 카메라 밖에 다시 배치하고 재사용한다.
- 분 전환 때 미완료 스포너는 기존 종류·간격·할당량으로 m마리를 끝까지 생성한다. 완료 후 현재 분의 작업을 시작하며, 지나간 분의 작업은 몰아서 실행하지 않는다. 동시에 활성화되는 스포너는 설정 개수를 넘지 않는다.
- 최초 생성도 n초 후 시작한다. 마지막 배치는 남은 수만 생성한다. m=0인 작업은 생성 없이 완료한다.
- 130마리 제한에 걸린 수는 생성 완료로 세지 않고 다음 간격에 재시도한다.
- 스포너를 새로 배치할 때 현재 카메라 경계 바깥과 여백을 사용한다. 이후 카메라가 이동해 스포너를 비출 때에는 다음 배치 생성 전에 다시 화면 밖으로 옮긴다.
- 몬스터는 스포너의 자식으로 두지 않는다. 스포너가 비활성화돼도 이미 나온 몬스터는 추적한다.
- 풀 대여 시 체력·사망 상태·추적 대상·물리·충돌·피격 색상을 복구하고 사망 시 풀에 반납한다. 풀을 사용하지 않는 기존 보스 등의 사망 처리는 유지한다.
- 기존 보스전 시작/종료 흐름과 연동해 일반 몬스터 생성과 진행 시간을 정지/재개한다. 보스 출현 때문에 Time.timeScale을 0으로 만들지 않는다.

## 기존 구조와 변경 범위

현재 EnemySpawner는 EnemyMvp.Runtime에 있고 PoolManager는 Assembly-CSharp에 있다. 직접 역참조할 수 없으므로 기존 어셈블리를 대규모 이동하지 않고 작은 계약과 Assembly-CSharp의 연결 컴포넌트로 연결한다. 기존 StopSpawning/RestartSpawning API와 직렬화 필드는 가능한 한 보존한다.

GiungTestScene에는 EnemyMvp 프리팹 하나와 스포너 하나가 연결돼 있다. 실제 분별 수치·추가 몬스터 종류는 개발자 설정으로 남긴다. 기존 보스 테스트 설정을 정식 3분 기획으로 임의 변경하지 않는다. 작업 중 사용자가 보스 등장 시간을 100초로 변경한 것을 보존했다. 다른 씬·프리팹·설정의 자동 재저장은 피한다.

## 검증과 사용자 확인 계획

- 배치 수량, 마지막 잔여 배치, 스포너별 m, 완료 비활성화, 분 경계의 미완료 작업, 동시 제한, 사망 후 풀 재대여의 상태 복구를 검증한다.
- 원본 Unity가 실행 중이면 같은 경로에 두 번째 에디터를 실행하지 않는다. 컴파일·테스트 실행 여부와 결과를 분리해 보고한다.
- Unity에서 GiungTestScene을 열고 해당 컴포넌트의 설정을 확인한 뒤 실행한다. 카메라 밖 스포너 배치, 배치별 추적 몬스터 증가, m 도달 후 비활성화, 다음 분 설정 적용, 사망 객체 재사용을 확인한다.
- 현재 사용자 씬 설정에서는 보스 테스트가 100초에 시작한다. 보스 처치 후 진행 시간 재개까지 확인한다. 문제가 있으면 Console의 첫 빨간 오류와 스포너 설정·진행 시간을 확인한다.
