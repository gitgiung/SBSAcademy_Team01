# 모바일 조작 배치와 전략 쿨타임

- 사용자 요구: 전략 버튼을 강공격 위로 합치고, 대시와 같은 쿨타임 표시를 제공하며, 일시정지의 설정에서 이동/버튼 묶음의 좌우를 바꾼다. 사용자는 설정의 앱 재실행 후 저장을 선택했다.
- 기본 버튼 순서는 전략/강공격/약공격/가드/대시. 기존 스킬·MP·쿨타임 수치와 입력 경로를 유지한다. 5개가 안전 영역 안에 들어가도록 묶음 높이·간격만 조정한다.
- 전략 쿨타임은 Player의 실제 시전 완료 시각과 당시 데이터 표의 기간을 읽는다. 실패/MP 부족은 시작하지 않고 일시정지 중 경과하지 않는다. 대시의 기존 원형 표시/초 표시 코드를 재사용한다.
- MobileControlLayout은 씬 내부 조작 배치만 소유한다. CanvasSafeArea의 기존 앵커 원본을 기준으로 두 묶음의 위치를 반전하며 조이스틱 배경 위치도 반전한다. 그림/텍스트/버튼 순서는 뒤집지 않는다. 별도 전역 매니저·이벤트 체계는 만들지 않는다.
- PlayerStatusPanel의 기존 설정에 조작 위치 버튼을 추가한다. 즉시 적용하고 PlayerPrefs에 저장한다. 게임 진행/팝업 정지 소유권은 바꾸지 않는다.
- 검증: 실제 씬의 5개 버튼 순서/좌표 검사, 전략 시전과 쿨타임 표시, 실패·정지·재입력, 좌우 반복 전환·컷아웃·비활성화/재활성화·저장 복원. Android 전체 빌드와 기기는 별도 확인 결과로 구분한다.
