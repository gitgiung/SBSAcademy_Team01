# 기본 공격 광탄 구현 계획

**목표:** 사용자가 선택한 흰 핵·옅은 금색 짧은 꼬리의 광탄과 작은 명중 빛을 기본 Bullet에 연결한다.

**설계:** pixelfx 생성 스크립트로 비행/명중 시트를 구워 기존 LightSkillVisuals.Baked 로딩을 재사용한다. 기본 Bullet 프리팹에만 선택적 시각 컴포넌트를 추가한다. Bullet의 이동·피해·콜라이더·수명·재사용 API는 유지하고, 별도 자식만 회전/스케일한다. 명중 효과는 기존 풀로 재사용하며 공격 판정이 없다.

**승인된 외형:** 흰색 중심, 옅은 금색 짧은 꼬리, 작은 명중 빛. 스킬보다 과하지 않은 기본 공격. 그림 수치는 연출용이며 게임 기획 수치를 변경하지 않는다.

- [x] 실제 Bullet 프리팹의 시각 연결 없음 실패를 확인하고 초기화/재사용/명중 검사를 만든다.
- [x] pixelfx 비행·명중 시트를 생성하고 미리보기를 확인한다.
- [x] 기본 프리팹에만 시각을 연결하고 일반/레거시 Bullet은 기존 그림을 유지한다.
- [x] 실제 컴파일 및 분리 Unity에서 방향·반복/정지·재사용·판정 보존을 검증한다. 기존 Bullet 수명 계산은 소스 변경 없음으로 확인했으며 실시간 Play 타임아웃 검증은 남아 있다.
- [x] 변경 검토·인수인계·사용자 확인 절차를 기록한다.

검증 결과: 분리 Unity assertion harness 15/15, 현재 Assembly-CSharp Roslyn 컴파일 exit0. 실제 MainScene Play/Android는 미실행. 비행 반복 경계의 float 오차를 검사로 발견하고 수정했다. 원본 Unity Test Runner 테스트는 실행하지 않았다.

직접 실행하며 별도 에이전트·브랜치 변경·커밋은 사용하지 않는다. 사용자 실행 중인 원본 Unity와 같은 프로젝트를 두 번째로 열지 않는다.
