# 타이머와 보스 등장

## 플레이 흐름

기존 `Assets/9.Scenes/EnemyMvpTestScene.unity`에서 Play한다.

1. 화면 위쪽에 `00:00` 타이머가 표시되고 일반 적이 생성된다.
2. 누적 전투 시간이 10초가 되면 타이머를 정확히 10초에 고정한다. 같은 위치에 `보스를 처치하세요.`를 표시하고 보스를 활성화한다.
3. 모든 연결된 일반 적 스포너의 생성을 중단하고, 이 씬의 활성·비활성 일반 적을 모두 제거한다. 보스와 플레이어 조작·공격은 계속 동작한다.
4. 보스가 죽으면 메시지 대신 `00:10`을 표시하고 그 시간부터 타이머를 재개한다. 스포너는 누적 생성 수를 초기화해 새 생성 주기를 시작한다.
5. 보스는 한 번만 등장한다. 일반 적은 스포너의 기존 Total Spawn Count(현재5), 간격(현재1초)에 따라 새로 생성되고 한도에 도달하면 멈춘다.

타이머는 분:초 형식이다. `01:05`는 1분5초다. 보스 전투 시간은 누적하지 않는다. 게임 전체를 일시정지하면(Time.timeScale=0) 타이머도 멈춘다.

## 설정과 코드

- Boss Encounter / BossEncounterController: Boss, Spawners, Boss Appear Time(기본10초).
- Encounter HUD / Timer / EncounterTimerView: Encounter와 Label 참조. 화면 상단 중앙의 동일 Text를 타이머·메시지로 전환한다.
- EnemySpawner.StopSpawning(): 생성만 명시적으로 중지. 컴포넌트를 껐다 켜도 이 중지 상태를 유지한다.
- EnemySpawner.RestartSpawning(): 생성 수와 중지 상태를 초기화하고 설정된 수의 적을 새로 생성한다.
- BossEncounterController는 EnemyHealth.Died를 구독해 보스 처치를 감지한다. 패턴 공격은 기존대로 로그만 출력한다.

스포너가 생성한 적은 해당 스포너가 속한 씬에 배치한다. 전투 전환의 정리 범위도 그 씬으로 제한해 다른 씬의 적은 제거하지 않는다. 일반 적 정리는 사망 보상을 발생시키는 TakeDamage 대신 비활성화 후 제거로 처리한다.

HUD는 uGUI의 화면 오버레이 Canvas와 해상도 대응 CanvasScaler를 사용한다. 텍스트는 클릭을 가로채지 않는다. 실행 시 OS의 한국어 글꼴을 사용하며 Windows 환경의 맑은 고딕으로 한국어 글리프 검증을 통과했다.

Tools > Enemy MVP > Add Timer And Boss Encounter로 같은 씬에 구성을 연결할 수 있다. 기존 저장 확인 창에서 취소하면 작업도 중단한다. 현재 제공된 씬에는 이미 연결되어 있다.

## 검증

Unity 6000.5.0f1에서 전체 PlayMode 테스트 41개 통과(실패·건너뜀0). 결과: `Logs/encounter-integrated.xml`.

검증 내용: 시간 형식, 시작 시 보스 숨김, 10초 정확한 정지와 메시지 전환, 활성·비활성 일반 적 제거, 보스전 중 추가 생성 방지, 한국어 글리프, 보스 처치 후 시간 재개, 이미 생성 한도에 도달한 스포너의 새 주기, 보스 재등장 방지, 기존 이동·공격·충돌·피격·사망 회귀 검사.

원본 에디터와 충돌을 피하려고 `.utmp/EnemyMvpValidation` 복사본에서 실행했다. 최종 소스와 씬은 원본에 반영됐으며 그래픽 없는 배치 모드이므로 화면 외형은 수동 확인한다.
