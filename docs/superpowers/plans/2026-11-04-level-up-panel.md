# 레벨업 패널 참고 이미지 적용

**Goal:** 사용자 첨부 이미지처럼 남색 배경 위 상단 제목과 가로 3장의 등급색 선택 카드를 표시한다.

**Architecture:** 기존 CombatPopupController/UI_CombatPopup의 정지·수명 계약을 보존하고, LevelUpSelectionPanel이 ContentRoot 안의 표시만 담당한다. 기존 StatusPanelUI의 Rect/Text/Image를 재사용한다.

**범위:** 카드 아이콘 자리, 이름, 영문 등급, 우측 정보 버튼, 액티브/패시브 구획, 설명과 하단 문구를 배치한다. 참고 이미지의 불꽃 탄환/common, 피해량 증가/Uncommon, 화염 심장/Rare는 표시 예시다. 보상·확률·스탯·획득 규칙을 새로 정하지 않는다. 실제 선택 데이터/콜백을 전달할 수 있으나 예시 클릭으로 보상을 지급하거나 팝업을 완료하지 않는다.

- [x] 기존 프리팹 참조를 보존하며 코드로 레벨업 전용 레이아웃 생성.
- [x] 실제 데이터 바인딩과 표시 예시 분리, 정보 버튼에는 제공받은 설명만 표시.
- [x] ShowLevelUp 경로에서 초기화하고 기존 정지/완료 API 유지.
- [x] 런타임/에디터 컴파일 0, 기존 독립 검증 4/4와 7/7, diff 통과. 최소화된 Unity 창에 UI 도구 연결 실패로 화면 확인은 남음.
- [x] Handoff와 사용자 확인 절차 갱신.

**Review Focus:** 팝업 중복 열기 시 UI 중복, 기존 ContentRoot 외부 콘텐츠 보존, 예시 카드의 무보상, 정보 버튼이 카드 선택까지 실행하지 않는지, 한글 줄바꿈/작은 해상도.
