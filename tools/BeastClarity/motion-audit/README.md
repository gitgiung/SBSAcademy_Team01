# 비스트 모션 점검 — 2026-11-17

현재 PNG 연속 프레임 시트8개와 애니메이션 클립73개의 키 시각을 검사했다. 실제 Unity/영상 재생 관찰은 하지 않았다. 아래의 시각적 끊김은 연속 자세에서 발견한 문제/후보이며 실제 재생 체감과 구분한다. 런타임 에셋과 코드는 변경하지 않았다. 프레임 번호는 0부터 센다.

## 우선 수정할 항목

1. **Body-charge 분리된 픽셀 조각**: South0의 머리 위, SouthEast0 등에서 몸과 떨어진 이전 행의 발처럼 보이는 조각이 포함된다. `body-charge.png` 및 실제 `Idle/animations/body-charge/south/0.png`에서 확인. 원본 시트 분할 경계의 잔여물로 추정된다. 생성물 알파/여백 검사만으로 걸러지지 않은 문제이며 앞선 선명도 검사 통과가 이 결함 없음을 뜻하지 않는다. 원본 기준으로 몸과 무관한 조각을 정리해야 한다.
2. **Move 마지막 자세의 두 배 유지**: BossWalk8방향 모두 7번 키0.5833333초, 같은 Sprite의 키0.6666667초, 종료0.75초. 7번 자세가 약0.1667초 유지되고 나머지 기본 간격은0.0833초다. 반복 끝에서 한 박자 멈추는 원인이 될 수 있다. 전체 길이0.75를 유지한 균등 배치와 길이 단축은 다른 수정이므로 검토 후 결정한다.
3. **Run West 외형 불일치**: West만 과거 run-source이고 다른 방향은 identity-v3다. `run.png`에서 West의 작은 상체·다른 얼굴/가슴 표시가 눈에 띈다. 방향 전환 시 다른 캐릭터/체격처럼 보일 위험. 사용자가 승인한 보행 순서를 유지하며 West 외형을 맞출 필요가 있다.
4. **Run NorthEast 시점 흔들림**: 2·6번은 인접1·3/5·7보다 가슴이 드러나는 정면 방향으로 몸이 돌아간다. 이동 방향은 같은데 몸통 시점이 주기적으로 바뀌는 모습. 연속 시트에서 확인했고 실제 체감은 재생 확인이 필요하다.

## 추가 재생 확인 후보

- Move North/South는 전체0~7에서 팔/어깨 변화가 작고 다리도 좁아, 실제 이동 속도에 따라 미끄러지는 것처럼 보일 수 있다. 발과 실제 이동 거리 동기화는 MainScene에서 확인해야 한다.
- SwipeBoth SouthEast/SouthWest의6→7에서 높이 들었던 손이 아래/전방으로 크게 이동한다. 공격 가속으로 의도된 빠른 스윙일 수 있어 정적 시트만으로 오류라고 확정하지 않는다. 24fps 정상속도에서 먼저 확인한다.
- 일반 Swipe South는3번 자세가0.25→0.666666673초(약0.4167초) 유지된다. 공격 준비를 위한 hold일 수 있으므로 단순히 제거하면 안 된다. 피해 이벤트0.791666673초와 종료 이벤트0.991666693초도 함께 고려해야 한다.
- 원형 공격 실제 코드에서는 PlaySlashAnimation에서 재생 직후 ApplyAreaDamage를 직접 호출한다. 인수인계의 과거 마지막 프레임 피해 설명과 현재 코드가 다르므로, 피해 시각을 옛 기록만으로 판단하지 않는다. 이번 점검에서 변경하지 않았다.
- Sprint 시트는 이미지가 있는 East/West만 표시했다. BossController의 현재 돌진 선택은 2페이즈BossRun, 그 외body-charge로 확인했으며 Sprint는 우선 수정 대상으로 잡지 않았다.

## 직접 확인

Unity 임포트 완료 → Animation에서 BossWalk_South의7→0, BossRun_NorthEast의1→2→3/5→6→7, BossRun_West와 East 비교, body-charge_South의0번을 확인한다. 정상은 불필요한 잔여물 없이 일정한 걷기 박자와 고정된 방향/체형을 유지하는 모습이다. 이어 Tools > Play From Title 해제 → MainScene에서 일반 추격/방향전환/돌진/원형공격 확인. 다른 그림이 보이면 클립 Sprite GUID와 Reimport, Console 첫 오류를 확인한다.

자동 검증 실행수: 이번 모션 품질 테스트0개. 점검 스크립트는 시트/키 시각 추출용이며 자연스러움을 자동 판정하지 않는다. 이전577개 정적 통과 결과를 모션 품질 통과로 재사용하지 않는다.
