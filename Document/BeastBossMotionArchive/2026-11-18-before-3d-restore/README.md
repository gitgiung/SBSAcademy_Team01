# 비스트 보스 수정 모션 보관

2026-11-18에 라이브 에셋을 `origin/feature/soul-pipeline-3d`의 수정 전 모션으로 되돌리기 전에, 그때의 비스트 보스 그림과 양손 공격 클립을 이 폴더에 복사했다.

폴더 구조는 프로젝트의 `Assets/2.Resources/Art/Beast_Zombie_Boss`와 같다. Unity가 이 복사본을 임포트하지 않도록 `Document` 아래에 둔다.

들어 있는 것:

- 다시 그린 달리기, 이동, 돌진, 할퀴기, 양손 공격 프레임과 그때의 스프라이트 설정
- 양손 공격 16프레임 클립 8개
- 라이브 폴더에서 뺀 양손 공격 8~15번 프레임과 `run/east_run.png`

스프라이트 GUID는 라이브 에셋과 같다. 이 그림을 다시 쓰려면 같은 경로의 PNG를 덮어쓰고, 양손 공격은 여기의 `.anim`도 함께 되돌린 뒤 Unity에서 해당 폴더를 Reimport한다.
