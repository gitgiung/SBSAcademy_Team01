# GiungTestScene 전투 팝업 설계

사용자 승인 범위: 레벨 시스템 없이 향후 이벤트가 호출할 진입점과 수동 확인 기능, 일시정지 버튼·팝업·‘뒤로가기’를 제작한다. 레벨업 효과·보상·선택지는 미정으로 둔다.

## 접근과 결정

- 레벨 시스템을 먼저 만드는 대신 `CombatPopupController.ShowLevelUp()`와 `CompleteLevelUp()`를 준비한다. 향후 레벨 이벤트 구독자는 이 메서드를 호출하고 콘텐츠 영역에 실제 선택지를 제공한다.
- 새 전역 이벤트 매니저나 별도 팝업 스택은 만들지 않는다. 씬에 연결된 UI 인스턴스를 기존 UIManager에 등록하고 동일한 중복·최상단 닫기 계약을 사용한다. Addressables 카탈로그가 없는 현재 씬에서도 동작한다.
- uGUI 프리팹으로 HUD의 일시정지 버튼, 화면 입력을 가리는 배경과 가운데 일시정지 패널, ‘뒤로가기’ 버튼을 만든다. 레벨업 패널은 제목과 빈 ContentRoot만 만든다. 수동 열기·완료는 Inspector 컨텍스트 메뉴이며 게임 화면에 테스트 보상·개발 안내를 넣지 않는다.
- 씬 로컬 controller가 열린 전투 팝업 집합을 소유한다. 첫 열기 전 timeScale을 저장하고 0으로 바꾸며 마지막 닫기에 복원한다. 중복 요청으로 정지 횟수를 늘리지 않는다. 외부 비활성화·파괴·UI.Clear·씬 종료도 해제한다. GameManager가 승리·패배 상태면 팝업 닫기로 전투를 재개하지 않는다. 외부에서 이미 정지한 경우 저장값 0을 유지한다.
- 보스전의 진행 타이머 정지와 분리한다. 보스가 등장해도 전투는 계속되고 팝업이 있을 때만 전투 전체를 정지한다. 현재 이동·공격·보스 코드의 scaled time 사용을 활용한다.

## 변경과 보존

UIManager에는 등록 API를 추가하고 CacheAll은 로드된 프리팹만 준비한다. 새 UI 프리팹과 한글 글꼴·라이선스를 추가한다. GiungTestScene에는 새 프리팹 인스턴스와 기존 GameManager 참조만 최소 연결한다. 기존 씬 객체·GUID·스폰 수치·패키지·Project Settings는 보존한다. 씬을 통째로 재저장하지 않는다.

## 확인 기준

중복 열기·겹친 팝업·최상단 닫기·버튼·기존 timeScale 복원·승패 정지 보존·외부 비활성화·씬 정리를 검증한다. 실제 GiungTestScene에서 이동·공격·스폰·진행 시간이 정지하고 UI 버튼은 동작하는지 검증한다. 기존 85개 테스트를 유지하고 실제 클립·Android·향후 성장 시스템 완성을 주장하지 않는다.
