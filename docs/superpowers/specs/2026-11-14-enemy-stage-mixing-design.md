# 일반 몬스터 단계 혼합 스폰 설계

## 목적과 합의

- 36개 웨이브마다 프리팹·가중치를 반복 입력하는 작업을 없앤다.
- `Assets/1.Prefabs/Normal Enemy/Temp_enemy`의 기존 24개 프리팹을 사용한다. 종류는 `Enemy_movespeed2`, `Enemy_movespeed3`, `Enemy_movespeed4`, `ZombieHound`이며 각 종류에 3/6/9/12/15/18min 단계가 있다.
- `_3min`은 0–3분, `_6min`은 3–6분 등 해당 구간의 몬스터다. 3분 경계부터 새 단계가 서서히 섞인다. 다음 단계를 경계 전에 내보내지 않는다.
- 기존 필드의 몬스터를 변환하거나 삭제하지 않고, 새 스폰 구성에만 적용한다.

## 검토한 방식

1. 변경 웨이브만 입력: 간단하지만 점진적인 혼합 비율을 계속 수동 작성해야 한다.
2. 단계·종류별 비율로 자동 계산: 사용자가 선택한 방향. 기존 단계 프리팹과 30초 웨이브를 활용한다.
3. 규칙으로 36개 웨이브 배열을 생성: 기존 실행 경로를 유지하기 쉽지만 재생성 때 수동 수정 관리가 필요하다.

## 제안하는 조작과 동작

- EnemySpawnDirector에 수동 웨이브/단계 혼합 선택을 추가한다. 기존 직렬화된 waves와 수동 모드는 보존한다.
- Inspector의 폴더 자동 등록 버튼으로 6단계 × 4종류를 연결한다. 누락·중복·필수 컴포넌트 오류가 있으면 적용 전에 알려준다. Undo를 지원하며 편집기에서만 폴더를 검색한다.
- 사용자는 단계 전환 시간과 종류별 초반/후반 상대 가중치를 편집한다. 종류별 비율은 진행 시간에 따라 보간하고, 단계 혼합 비율과 곱해 최종 가중치를 계산한다.
- 첫 3분은 첫 단계만 사용한다. 이후 경계부터 이전 단계와 현재 단계를 혼합한다. 전환 완료 후 현재 단계만 사용한다. 마지막은 18min 프리팹까지 사용한다.
- 혼합 비율은 30초 웨이브 단위로 갱신한다. 스폰 시도 예산·동시 활성 130마리 제한·18분 종료·진행 일시정지·XP 규칙은 유지한다.
- 기존 가중 스케줄러와 SceneEnemyPool/Managers.Pool을 재사용한다. 새로운 전역 매니저를 만들지 않는다.
- 배포 연결은 필요한 Enemy Spawn System 프리팹의 해당 컴포넌트만 최소 수정한다. 씬에 덮어쓴 설정이 있는지도 확인한다. 기존 프리팹 GUID와 몬스터 능력치는 유지한다.

## 승인된 초기값

- 전환 시간: 우선 90초. 예를 들어 3:00부터 새 단계가 섞이고 4:30부터 새 단계만 등장한다. 경계 시점의 새 단계 비율은 0이며 이후 30초마다 증가한다.
- 종류별 초반/후반 가중치: 우선 모두 1로 두어 네 종류를 균등하게 사용한다. 빠른 적·들개의 후반 비중은 사용자가 Inspector에서 높일 수 있다.
- 위 수치는 사용자가 2026-11-14 승인한 플레이테스트 초기값이며 확정 기획 수치는 아니다.

## 검증과 제한

- 단계 경계 전 조기 등장 금지, 혼합 중 이전/현재 단계만 선택, 완료 후 이전 단계 제외, 마지막 단계, 0 가중치, 설정 누락, 기존 수동 웨이브 회귀를 검증한다.
- 보스전 진행 시간 정지 시 혼합도 멈추는지, 큰 Tick에서도 웨이브 경계를 정확히 처리하는지 확인한다.
- 실행 가능한 컴파일·테스트를 수행하고 Unity Play·Android·실기기 미검증은 구분해 보고한다. 열려 있는 프로젝트를 두 번째 Unity로 열지 않는다.
- 구현 후 사용자 확인: Tools > Play From Title 해제 → MainScene → Enemy Spawn System의 Inspector 설정 확인 → Play에서 단계 경계 전후 새로 생성되는 프리팹 이름 확인. 오류 시 Console 첫 오류와 자동 등록 누락, 씬 Overrides, 전환 시간·가중치를 확인한다.
